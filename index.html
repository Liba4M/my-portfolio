TutorGenie

Tools Used: Next.js, TypeScript, Supabase, Azure OpenAI, Tailwind CSS, PostgreSQL

TutorGenie is an AI-powered tutor support platform designed to help tutors create personalised lesson plans, generate targeted feedback, and organise student learning more efficiently. The project brings together full-stack development, database design, authentication, AI integration, and a user-focused interface to solve a real teaching workflow problem. I built the platform to make lesson preparation faster, more structured, and more tailored to each student’s needs, while strengthening my skills in building scalable, practical, and polished software products.

Global CO₂ Emissions Analysis

Tools Used: Python, Pandas, Matplotlib, Seaborn, Jupyter Notebook

Passionate about sustainability, I explored the Our World in Data CO₂ Emissions dataset to uncover global trends and insights. This project focused on visualising long-term CO₂ emission patterns across major countries, identifying top emitters by both total and per capita emissions, analysing the relationship between GDP and emissions, and breaking down emissions by fuel type including coal, oil, and gas. Through insightful visualisations and data wrangling, this project revealed global disparities and reinforced my passion for sustainability through data-driven impact.
